# Security policy

## Reporting a vulnerability

Please report security vulnerabilities in this repository or in the live website at https://buildwisegroup.dev **privately**, through GitHub private vulnerability reporting:

https://github.com/JosephIwe/buildwise-group-landing-page/security/advisories/new

For a problem on the live site rather than in the code, start the title with "Live site:" and give the exact address you tested.

Please do not open a public issue or pull request for a vulnerability, and do not put vulnerability details in the website's project enquiry form or on WhatsApp. If you can't use GitHub, use one of those channels only to say you have a security report, and we will agree a private way to receive it.

The full policy, including what to include, testing guidelines and how reports are handled, is at https://buildwisegroup.dev/security.
