# BuildWise Group
# Every public page is open to search engines and AI search assistants. Scanner answers
# never appear in a URL a crawler can request: report links keep them after "#", which
# browsers never send to the server, and a page showing a report is marked noindex.
# Drafts under /insights are marked noindex on the page itself until they are approved.
#
# Search and AI-search crawlers are named explicitly so the decision is on record.
# A crawler obeys only the most specific group that names it, so each group repeats
# the /api/ rule. Training crawlers (GPTBot, Google-Extended, CCBot, ...) are not
# named and fall under "*", which allows them: blocking them is a separate business
# decision and does not affect search visibility, according to OpenAI and Google.
#
# Robots rules are not the whole story: Cloudflare's bot settings (Block AI bots,
# AI Crawl Control, managed robots.txt) can block crawlers before they read this file.
